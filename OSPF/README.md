# Open Shortest Path First (OSPF)

## Overview

This lab demonstrates the configuration of Open Shortest Path First (OSPF) using Cisco Packet Tracer.

The network uses OSPF as a dynamic routing protocol to automatically exchange routing information between routers and provide end-to-end connectivity.

---

## Objectives

- Configure OSPF on Cisco routers.
- Advertise connected networks.
- Establish OSPF neighbor relationships.
- Build dynamic routing tables.
- Verify end-to-end connectivity.

---

## Technologies Used

- Cisco Packet Tracer
- IPv4
- Open Shortest Path First (OSPF)

---

## Topology

The lab consists of multiple routers connected through serial and Ethernet links to demonstrate dynamic routing using OSPF.
