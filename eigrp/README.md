# Enhanced Interior Gateway Routing Protocol (EIGRP)

## Overview

This lab demonstrates the configuration of Enhanced Interior Gateway Routing Protocol (EIGRP) using Cisco Packet Tracer.

The network uses EIGRP as a dynamic routing protocol to exchange routing information automatically and provide efficient communication between routers.

---

## Objectives

- Configure EIGRP on Cisco routers.
- Advertise connected networks.
- Establish EIGRP neighbor relationships.
- Build dynamic routing tables.
- Verify end-to-end connectivity.

---

## Technologies Used

- Cisco Packet Tracer
- IPv4
- Enhanced Interior Gateway Routing Protocol (EIGRP)

---

## Topology

The lab consists of multiple Cisco routers connected through serial and Ethernet links to demonstrate dynamic routing using EIGRP.
