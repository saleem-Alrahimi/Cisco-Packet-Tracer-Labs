# Border Gateway Protocol (BGP)

## Overview

This lab demonstrates the basic configuration of Border Gateway Protocol (BGP) using Cisco Packet Tracer.

The topology simulates communication between multiple autonomous systems by configuring BGP neighbor relationships and exchanging routing information.

---

## Objectives

- Configure BGP on Cisco routers.
- Establish BGP neighbor relationships.
- Advertise network prefixes.
- Verify route propagation.
- Test end-to-end connectivity.

---

## Technologies Used

- Cisco Packet Tracer
- IPv4
- Border Gateway Protocol (BGP)

---

## Topology

The lab consists of multiple Cisco routers connected through serial and Ethernet links to simulate inter-domain routing using BGP.
