# Spanning Tree Protocol (STP)

## Overview

This lab demonstrates the configuration and operation of the Spanning Tree Protocol (STP) using Cisco Packet Tracer.

The network is designed to prevent switching loops by electing a Root Bridge and placing redundant links into a blocking state while maintaining network redundancy.

---

## Objectives

- Configure STP on Cisco switches.
- Prevent Layer 2 switching loops.
- Elect the Root Bridge.
- Verify port roles and states.
- Maintain network redundancy.

---

## Technologies Used

- Cisco Packet Tracer
- Ethernet Switching
- Spanning Tree Protocol (STP)

---

## Topology

The lab consists of multiple Cisco switches connected through redundant links to demonstrate the operation of STP and loop prevention.
