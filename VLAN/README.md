
# VLAN Configuration

## Overview

This lab demonstrates the configuration of Virtual Local Area Networks (VLANs) using Cisco Packet Tracer.

## Objectives

- Create VLANs.
- Assign switch ports to VLANs.
- Configure trunk links.
- Configure inter-VLAN routing.
- Verify network connectivity.

## Technologies Used

- Cisco Packet Tracer
- VLAN
- Trunk
- Router-on-a-Stick
- IPv4
